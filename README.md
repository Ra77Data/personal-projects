Automatizar respuestas y facilitar la atención de consultas técnicas mediante mensajería.

**Tecnologías principales:**

- JavaScript
- WhatsApp
- Automatización

🔗 Repositorio: [whats_bot](https://github.com/Ra77Data/whats_bot)

Aplicación web sencilla para consultar información del clima.

**Tecnologías principales:**

**Tecnologías principales:**

- ChromeOS
- Crostini
- Automatización / scripting
